IT Help Desk Ticket Management System


Project Overview

This project is an Excel-based IT Help Desk Ticket Management System designed to organize, track, and monitor technical support requests.

It represents a corporate IT support setting where technicians handle tickets and employees report technical issues.

Project Objectives

- Organize IT support requests.
- Track ticket priority and status.
- Keep track of the ticket's age.
- Identify overdue support requests.
- Display ticket statistics through a dashboard.

Tools Used

- Microsoft Excel
- Microsoft Forms
- Excel formulas
- Data Validation
- Conditional Formatting
- Excel Tables and Charts

Key Features

- Unique ticket identification numbers
- Employee and issue information tracking
- Issue category dropdown menus
- Priority and status dropdown menus
- Automatic ticket age calculations
- Overdue ticket alerts
- Dashboard with ticket statistics and charts

Skills Practiced

- IT help desk workflows
- Spreadsheet organization
- Data management
- Formula creation
- Dashboard development
- Troubleshooting and testing

Testing

The system was tested using fictional employee records. Ticket counts, category totals, ticket ages (days), and overdue alerts were checked to confirm that the workbook updated correctly.

Additional Feature

A Microsoft Forms IT Support Request Form was created to collect employee names, issue categories, and problem descriptions. Responses sync to a separate Excel workbook in OneDrive.

Automatic transfer into the main ticket tracker was not implemented because the school account did not provide access to a Power Automate environment.

Privacy

All employee names and ticket information are fictional and used for educational demonstration purposes.
